# Multi-Agent Equity Research System
This project automates equity research using multiple AI agents built with N8N.

## Project Overview

This project automates equity research using multiple AI agents built with N8N.

The workflow gathers information from various external sources, processes the data through Large Language Models (LLMs), and generates consolidated fundamental and technical analysis to support investment research activities.

---

## Business Problem

Equity research is often:

- Time-consuming
- Repetitive
- Labor-intensive

Research teams spend significant time collecting information, reviewing multiple sources and summarizing findings before meaningful analysis can begin.

Key challenges included:

- Manual information gathering from multiple sources
- Time-intensive research workflows
- Inconsistent research outputs
- Limited scalability for repetitive analysis tasks

---

## Project Objective

Build an AI-powered workflow capable of:

- Gathering external information automatically
- Summarizing large amounts of data
- Generating consolidated research reports
- Supporting faster investment analysis and decision-making

---

## Solution Architecture

### Workflow Components
